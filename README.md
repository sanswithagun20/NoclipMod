A Noclip mod that has ground detector, airwalk, and wall transfer.

Has been tested on Melonloader 0.7.3 and BoneLib 3.2.2, if lower, use at your own risk.
Put the Noclip_V1.4.dll into your Mods folder.

Activating/deactivating noclip: press the y button once.

Activating/deactivating ground detector: press the y button twice, noclip will activate/deactivate as well.

Activating/deactivating air walk: use the menu to toggle it on, will only activate when ground detector is on.

Activating/deactivating walltransfer: toggle it on in the menu, then press b while standing in front of a wall.

WARNING:
This is a experimental mod, which means it will not be perfect, issues can happen,
if you find one report it to me on my github repository.

How to report an issue:
Click my github link on the thunderstore page. Go to the top line where it says Code, Issues Pull requests, etc.. and press issues.
go to the right and press the green button 'New issue', if its grey, log into github.
type out the issues you are having, make a title and if you can a video or image would help, and press create.
It will not be garenteed that I will fix it and it can depend on if I can replicate it or if its not to bad to fix.

By the way it is not recommended to use 1.4.0 and to update to 1.4.5, since there was a bug with wall transfer that I missed and it is fixed on 1.4.5.

But now it isn't garenteed for wall transfer to go through any wall.
