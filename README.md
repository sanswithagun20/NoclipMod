A Noclip mod that has ground detector, airwalk, and wall transfer.

Has been tested on Melonloader 0.7.3 and BoneLib 3.2.2, if lower, use at your own risk. 
Put the Noclip_V1.3.dll into your Mods folder.

For activating/deactivating noclip: Press the Y button once.
For activating/deactivating Ground detector: Press the Y button twice, noclip will activate/deactivate as well.
For activating/deactivating Air walk: Use the menu to toggle it on, will only activate when ground detector is on.
For activating/deactivating WallTransfer: Toggle it on in the menu, then press B while standing in front of a wall.

WARNING:
This is a experimental mod, which means it will not be perfect, issues can happen, 
if you find one report it to me on my github repository.
